# Task T4 — download progress (B13) and dead `--verbose` (B18)

## Context

Two smaller items from the backlog. Both are small, but they are the kind of
thing a user notices in the first minute of using the tool.

```

```

## Rules

- Touch `internal/cli/download.go`, `internal/cli/install.go`,
  `internal/cli/add.go`, `internal/cli/root.go` only.
- No new dependencies.
- Do not break `--json` output: progress goes to stderr so stdout stays clean.

## B13. Show download progress

`internal/ui` already has a `Progress` bar (`ui.NewProgress`) that nothing
uses. `add` and `import` download 10–50 MB jars with no indication, which reads
as a hang.

- Thread a progress reporter through `fetchFile` (`internal/cli/download.go`)
  and the download loop in `internal/mrpack/install.go` if it does not already
  accept one. If touching `internal/mrpack` risks a conflict with another
  branch, confine yourself to `internal/cli` and note the omission.
- The bar must show the mod name, bytes transferred, total and rate, and
  disappear cleanly on completion or failure. It should disable itself
  automatically when stderr is not a TTY, which `ui.Progress` already handles.
- Never print progress in `--json` or `--quiet` mode.
- A failed checksum must still leave a clear error, not a stuck bar: call
  `Done` on every path including the error return.

## B18. Make `--verbose` do something, or remove it

The global `-v/--verbose` flag is parsed and never read. Wire it to something
honest rather than inventing a logging framework:

- On verbose, print the resolution of each jar to stderr: file name, the
  method that matched (`hash`, `slug`, `curseforge-id`, `name`, `manual`),
  the project, and the confidence. This is genuinely the most useful
  diagnostic when identification looks wrong, and the information already
  exists in `resolver.Result`.
- Keep it on stderr so `--json` remains parseable.

If wiring it cleanly requires more surgery than it is worth, remove the flag
from the global set and from the README instead. Say which you chose and why.
